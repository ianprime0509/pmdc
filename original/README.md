# Original PMD sources

This directory contains the original PMD sources behind the translation, for
comparison, taken from [KAJA's
website](http://www5.airnet.ne.jp/kajapon/tool.html).

For convenience, all files have been converted from Shift JIS (CP932) with PC-98
extensions to UTF-8. A script `convert.py` is available in this directory to
perform the conversion.
